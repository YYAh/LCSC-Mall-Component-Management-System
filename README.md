# 嘉立创元器件与 12 行样品册库存管理系统 (LCSC-Mall-Component-Management-System)

专为电子工程师、创客与实验室打造的**元器件全流程库存、样品册插槽与专属标签打印管理系统**。支持 **100% 永久免费单机模式** 与 **局域网自建 Node.js + SQLite 服务端多端实时同步模式**。

---

## 🌟 核心功能特色

1. **📱 100% 永久免费单机独立运行 · 零成本免维护**
   - **零服务器成本**：数据安全存储在微信本地，无需支付任何云开发月费。
   - **局域网多端同步**：电脑双击运行 `启动后端服务.bat`，手机与电脑在同一局域网 WiFi 下即时同步。
2. **📊 Excel (`.xlsx` / `.xls` / `.csv`) 毫秒级直接导入与导出**
   - 内置纯 JavaScript 零依赖解压与解析引擎，微信聊天记录中直接选取 `.xlsx` 文件即可秒级解析并全自动分配 12 行样品册插槽！
   - 支持一键导出全库物料为标准 Excel / CSV 表格（含 UTF-8 BOM，在 Windows Excel 打开 0 乱码）。
3. **🏷️ 52+ 标准元器件大类库 & 贴片阻容严格解码**
   - 全面覆盖 52+ 常见元器件分类（主控MCU、DC-DC、LDO、运放、MOS、二极管、TVS/ESD、轻触开关、贴片阻容等），并支持动态自定义扩展。
   - 内置贴片电阻/电容 EIA-96 与 4 位码精准解码器，自动还原真实阻值（如 `1kΩ ±1%`、`100Ω`、`100kΩ`）与品牌。
4. **📖 12 行样品册专属仓位体系**
   - 专为 0603/0805 贴片样品册深度定制，每页 12 行插槽翻页可视化直观呈现。
   - ⚡ **智能推荐空位**：录入时一键自动寻找对应类别样品册中的下一个空闲插槽（如 `B01-P01-R02`）。
5. **🖨️ 专属标签排版与蓝牙 BLE 热敏打印**
   - 内置 **30×10mm（样品册专用细长标签条）**、**40×20mm（标准元件盒）**、**50×30mm（大号抽屉）** 模板。
   - 手机端支持蓝牙 BLE 直连热敏打印机（兼容 TSPL / CPCL 双指令集，支持 UTF-8 中文防乱码）。

## 🚀 极速上手使用指南

### 1. 微信小程序端快速运行
1. 下载并安装官方 **[微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)**。
2. 打开微信开发者工具，点击 **「导入项目」**：
   - **目录**：选择本项目根目录；
   - **AppID**：填写您的小程序 AppID 或测试号；
3. 点击开发者工具右上角 **「详情」 -> 「本地设置」 -> 勾选「不校验合法域名、web-view (业务域名)、TLS 版本以及 HTTPS 证书」**；
4. 点击 **「预览」** 或 **「真机调试」**，微信扫码即可随身使用！

### 2. （可选）开启电脑局域网自建后端服务
1. 确保电脑已安装 [Node.js](https://nodejs.org/)；
2. 双击项目根目录下的 **`启动后端服务.bat`**（或在 `backend` 目录下执行 `npm install && npm start`）；
3. 打开小程序底部导航的 **【设置】** -> 选择 **【💻 局域网自建服务器】** -> 填写提示的电脑 IP 地址（如 `http://192.168.x.x:3000`）点击“测试并保存”即可！

## 📂 工程目录结构

```
├── miniprogram/              # 微信小程序前端源码
│   ├── pages/
│   │   ├── index/            # 首页看板与出入库动态
│   │   ├── scan/             # 扫码录入与智能分配插槽
│   │   ├── components/       # 元器件物料库、批量管理与 Excel 导入导出
│   │   ├── detail/           # 元件详情与规格书
│   │   ├── books/            # 样品册 12 行插槽可视化视图
│   │   ├── print/            # 专属标签排版与蓝牙打印
│   │   └── settings/         # 运行模式切换与局域网服务配置
│   ├── utils/
│   │   ├── api.js            # 统一数据适配层 (Local / REST)
│   │   ├── classifier.js     # 52+ 大类智能分类与阻容解码器
│   │   ├── excelParser.js    # 零依赖纯前端 XLSX/CSV 解析引擎
│   │   ├── blePrinter.js     # 蓝牙 BLE 热敏打印驱动 (TSPL/CPCL)
│   │   ├── qrParser.js       # 立创二维码解析器
│   │   └── qrcode.js         # 矢量二维码 Canvas 渲染引擎
│   ├── app.json
│   ├── app.js
│   └── app.wxss
│
├── backend/                  # 局域网/私有服务器端 (Node.js + Express + SQLite)
│   ├── routes/               # REST API 路由
│   ├── db.js                 # SQLite 数据库模型与默认样品册
│   ├── jlcService.js         # 嘉立创/EasyEDA 元件库接口抓取
│   └── server.js             # HTTP 后端服务入口
│
├── test_server.js            # 后端集成测试套件
├── 启动后端服务.bat          # Windows 一键启动脚本
└── project.config.json       # 微信小程序工程配置文件
```
